How to Diagnose the Issue

  1. Open browser dev tools (F12) and go to Console
  2. Try logging in via the login form
  3. Check the console output for:    - Token length
    - Token parts count (should be 3)    - Token preview
  4. Check server logs (/tmp/php.log) for:
    - What error message the kreait library is returning
    - Token payload claims    - Timestamp comparison
  Next Steps to Fix

  php -S localhost:8000 > /tmp/php.log 2>&1 &
