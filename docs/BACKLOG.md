# Product Backlog Items (PBI)

Priorisierung nach dem MoSCoW-Prinzip (Must have, Should have, Could have, Won't have).

## Must Haves (Prio 1)
- **PBI-01**: **Responsives Landingpage Design**. High-End Look & Feel für die Organisation.
- **PBI-02**: **News/Blog System (CMS)**. Datenhaltung in Firestore, Anzeige im Frontend.
- **PBI-03**: **User Authentifizierung**. Firebase Auth Integration für Login/Profil.
- **PBI-04**: **Einfacher Warenkorb**. Produkte hinzufügen, Menge ändern, lokal speichern.
- **PBI-05**: **"Kaufen" Signal**. Abschluss des Kaufvorgangs (Simulation/Webhook-Vorbereitung).

## Should Haves (Prio 2)
- **PBI-06**: **Newsletter Signup**. Integration von Resend oder Mailchimp API.
- **PBI-07**: **Admin Dashboard**. Einfaches Interface zum Erstellen von Blogposts.
- **PBI-08**: **Global Search**. Suche über Blogposts und Produkte hinweg.

## Could Haves (Prio 3)
- **PBI-09**: **Dark Mode Support**. Automatisch/Manuell umschaltbar.
- **PBI-10**: **AI Product Descriptions**. Automatische Generierung von Texten via Gemini.

## Won't Have (für dieses MVP)
- **Vollständige Zahlungsabwicklung**. (Nur bis zum Button "Kaufen").
- **Bestandsmanagement (Inventory)**.
